# Скриншоты продукта

Актуальная галерея для корневого README снята 31 октября 2026 года с работающей версии `7789284`.

- `board-current-day.jpg`, `board-current-night.jpg` — компактная Kanban-доска с вкладкой «Эскиз».
- `today-current.jpg` — обзор «Мой день».
- `sketch-current-day.jpg`, `sketch-current-night.jpg` — схема согласования API, инструменты, магнитный стиратель и подписи в двух темах.
- `mobile-current-board.jpg`, `mobile-current-editor.jpg` — мобильная доска с новой навигацией и редактор задачи, 412 × 915.

Использована отдельная демонстрационная база на localhost:3102. Реальные задачи владельца не участвовали в съёмке. Настольные снимки — 1280 × 720; масштаб эскиза 65% выбран штатной кнопкой вписывания. Изображения сняты непосредственно в браузере без ретуши интерфейса.

Файлы без `current` — предыдущие снимки, оставленные для истории; корневой README использует новую галерею.
