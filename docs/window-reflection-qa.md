# Отражение по пользовательскому рендеру · 31 октября 2026

- TypeScript и production-сборка проходят.
- Новый фотографический материал проверен в дневной и вечерней темах. В браузере WebGL-компонент перешёл в `reflection-ready`; ошибок в журнале нет.
- Сравнение двух снимков через NSBitmapImageRep: средняя разница RGB в открытом участке листвы — 4.785 из 255; в участке оконной рамы — 0; на нейтральной эмали — 0. Таким образом, двигается листва, а не вся фотография.
- Галочка отключения удаляет компонент целиком; повторное включение снова создаёт рабочий canvas.
- При размере окна 390×844 canvas пересчитался до 356×800; документ остался 390×844 без внешней прокрутки.
- Настройки пользователя возвращены к вечерней теме с включённым отражением. Задачи не изменялись.
- Системное уменьшение движения, невидимость вкладки и отсутствие WebGL обрабатываются в компоненте; отдельная эмуляция этих режимов в браузере не выполнялась.
