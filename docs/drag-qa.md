# Перенос стикеров · 31 октября 2026

Устранена причина возврата карточки: визуальный порядок теперь предварительно обновляется при наведении и остаётся на месте до ответа сервера. DragOverlay приземляется на реальный узел в целевой колонке. Автоматическое масштабирование до размеров колонки отключено. Соседние карточки перемещаются из предыдущих экранных координат с коротким подъёмом и изменением тени; попадание курсора проверяется по неподвижным координатам раскладки, а не по анимированной позиции.

Рисунок загнутого края теперь определяется идентификатором задачи и не меняется при смене позиции в списке. Перед подтверждением сервера интерфейс сообщает «Сохраняю…», без преждевременного сообщения об успехе.

## Проверки

- `npm run build`: TypeScript и production-сборка успешны.
- `npm test`: 10 проверок, включая новые случаи многократного переноса, стабильного места вставки, перестановки и работы при фильтрации.
- Браузер: отдельная доска в памяти на порту 3001; тестовый сервер задерживал ответ на 1500 мс. Рабочие задачи пользователя не менялись.
- Перенос мышью и клавиатурой между заполненными колонками: до ответа сервера карточка уже в целевой колонке, состояние «Сохраняю…»; после ответа остаётся там же.
- Перенос мышью в пустую колонку и перестановка кнопкой «Ниже» работают.
- Escape отменяет предварительное перемещение без сохранения.
- Принудительный отказ сервера: карточка возвращается в исходную колонку, отображается ошибка, временные слои удаляются.
- Клавиатурное перемещение вниз в длинной колонке прокручивает её к месту вставки; placeholder полностью находится внутри видимой области.
- После завершения нет зависших overlay или placeholder; ошибок браузера при финальной проверке нет.
- Системное уменьшение движения предусмотрено CSS и нулевой длительностью JS-анимаций; отдельно не эмулировалось.
