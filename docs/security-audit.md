# Аудит безопасности — 31 октября 2026 года

## Вывод

В проверенных сценариях не обнаружен работающий обход защиты локального API из постороннего сайта, исполнение пользовательского HTML/JavaScript, SQL-инъекция или чтение файлов вне папки интерфейса. Это результат ограниченного аудита кода и тестов, а не гарантия отсутствия уязвимостей.

Текущая версия предназначена для одного владельца на доверенном компьютере. Публиковать API в интернете пока нельзя: входа, разграничения прав и изоляции пользователей нет. Установленный на проверяемом компьютере Node.js 24.13.0 требует обновления независимо от исправлений приложения.

## Область и метод

Проверены сервер Fastify, SQLite/Drizzle, схемы Zod, импорт/экспорт, зависимости задач, вывод карточек и SVG эскиза, локальный запуск, статические файлы и npm-зависимости. Негативные запросы выполнялись через настоящий Fastify API с отдельными временными SQLite-базами. Для XSS проверялся HTML/SVG, сформированный React; это не динамический браузерный пентест. Пользовательская база не использовалась для атакующих запросов.

Проверены права файлов на macOS и ограниченный набор шаблонов секретов в отслеживаемых Git файлах. Полная история Git, ОС, расширения браузера, цепочка поставки npm и физические устройства отдельно не исследовались. Нагрузочный сетевой тест slowloris и внешняя атака на развёрнутый сервер не выполнялись.

### Воспроизводимый дефект импорта

Цепочка из 10 000 задач, каждая из которых зависит от следующей, укладывалась в разрешённый объём импорта: примерно 5,8 МБ при лимите 12 МиБ. Старый `validateBoard` завершался `RangeError: Maximum call stack size exceeded`. Теперь алгоритм проверяет граф без рекурсии: допустимая цепочка проходит, замыкание той же цепочки корректно отклоняется. Потеря данных или завершение процесса при прежнем дефекте не были установлены.

### Защита браузерного доступа

Сохранились точный список допустимых Host, проверка Origin и `X-Board-Request` для записи, отсутствие разрешающего CORS и обязательный JSON. Добавлены проверка Origin/Fetch Metadata для чтения, `Cross-Origin-Resource-Policy: same-origin`, `Cross-Origin-Opener-Policy: same-origin`, `X-Frame-Options: DENY` и ограничение доступа к устройствам через Permissions Policy. Уже имелась CSP с запретом внешних скриптов и встраивания во фреймы.

Проверяются также соседние порты localhost: same-site не означает same-origin. Клиенты командной строки без браузерных заголовков могут читать API; локальная программа может подделать заголовки. Это намеренная граница личного режима, а не аутентификация пользователя. Подход к защите браузерных запросов согласуется с [рекомендациями OWASP по CSRF](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html).

Конечные таймауты добавлены как защита доступности. Fastify рекомендует задавать requestTimeout при работе без защищающего обратного прокси: [Server reference](https://fastify.dev/docs/latest/Reference/Server/).

### Зависимости и Node.js

Онлайн-проверка `npm audit` сообщила **0 известных уязвимостей** для установленного дерева production- и dev-зависимостей. Это не проверка безопасности каждого пакета и не проверка исполняемой среды Node.js.

Установлен Node.js **24.13.0**. Для ветки 24 опубликован выпуск безопасности **24.22.1 от 21 октября 2026 года**. Нужно обновить Node.js до актуального исправленного выпуска 24 LTS, затем повторить сборку и тесты. Эксплуатация конкретной уязвимости Node.js через это приложение не доказана. Источники: [выпуск 24.22.1](https://nodejs.org/en/blog/release/v24.22.1), [обновления безопасности октября](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases).

## Подтверждённые меры защиты

- Сервер слушает `127.0.0.1:3000`; изменяющие запросы проверяются до выполнения операции.
- Запросы к данным параметризованы. SQL-подобный текст сохраняется как текст.
- React экранирует текст задач и подписи SVG. Ссылки с `javascript:`, `data:` и `file:` отклоняются схемой.
- Импорт проверяет структуру и связи; изменения транзакционные. Ошибки импорта и миграций проверены на сохранность данных.
- Размер тела ограничен 12 МиБ, схемы ограничивают число сущностей и точек эскиза.
- На проверенном Mac `.local` имеет права `0700`, база и её WAL/SHM — `0600`. Проверка Windows ACL не проводилась.
- `.local`, базы, дампы, файлы окружения и ключи исключены из Git; отслеживаемые локальные базы/ключи при проверке не найдены.

## Проверки

Добавлен `tests/security.test.ts` с пятью группами сценариев: происхождение запросов и Host; повреждённый JSON, prototype-ключи, объём и опасные ссылки; обход путей статики; экранирование HTML/SVG; предельная цепочка зависимостей и цикл.

Проверочный набор: **28 тестов основного запуска и 6 интеграционных тестов SQLite/API**, проверка TypeScript и production-сборка. Интеграционные сценарии включают транзакционный откат, конфликт ревизий, резервные копии, восстановление, неудачную миграцию и сохранность после перезапуска. Тесты безопасности работают с временными данными.

Все указанные проверки прошли. Перед применением исправлений создана резервная копия рабочей SQLite-базы. Приложение перезапущено: содержимое доски до и после полностью совпало, HTML и health отвечают 200, запрос с посторонним Origin — 403, новые защитные заголовки активны. Прослушивание осталось только на `127.0.0.1:3000`.

## До серверной версии

Нужны отдельная модель угроз, аутентификация, проверка прав на каждый объект и операцию, изоляция данных владельцев, HTTPS, безопасные сессии, ограничения частоты/ресурсов, журнал значимых действий, политика обновлений и проверенное восстановление резервных копий. После этого — повторный аудит сетевого развёртывания. Простого изменения адреса прослушивания или добавления Docker недостаточно.
