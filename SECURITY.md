# Безопасность локальной версии

«Моя доска» рассчитана на одного владельца и доверенный компьютер. Сервер слушает только `127.0.0.1`. Проверки Host, Origin и Fetch Metadata, специальный заголовок записи и CSP ограничивают доступ из посторонних сайтов, но **не заменяют авторизацию**. Программа, работающая на вашем компьютере, может обратиться к локальному API.

Не открывайте текущую версию в интернете через туннель, обратный прокси или изменение адреса прослушивания. Для серверной версии сначала нужны вход, проверка прав на каждую операцию, изоляция данных пользователей, HTTPS и ограничения запросов.

Используйте актуальный исправленный выпуск Node.js 24 LTS; на дату аудита 31 октября 2026 года — не ниже **24.22.1**. Проверяйте [официальные обновления безопасности Node.js](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases). Обновление npm-пакетов не обновляет сам Node.js.

База `.local/board.sqlite`, резервные копии, JSON-экспорты и черновики браузера содержат пользовательские данные без прикладного шифрования. Для защиты при потере компьютера используйте шифрование диска и отдельную учётную запись ОС. Не добавляйте `.local`, экспорты с рабочими данными и секреты в репозиторий. Перед обновлением сохраняйте копию: `npm run backup`.

Проверки разработчика:

```sh
npm audit
npm test
npm run test:integration
npm run build
```

Автоматические проверки дополняют аудит, но не доказывают отсутствие уязвимостей. Обнаружив проблему, не публикуйте в открытом issue реальные данные, токены или рабочую базу; используйте минимальный пример с вымышленными данными.

Подробности и ограничения проверки: [отчёт от 31 октября 2026 года](docs/security-audit.md).
