# Мобильные концепты

Созданы встроенным imagegen. Это статические варианты UI/UX, а не реализованный интерфейс. Текст, размеры и отдельные иконки требуют уточнения при реализации на реальных ширинах 320–430 CSS px.

## Предложение

Основной режим доски — компактный вертикальный список со сворачиваемыми этапами (02). Дополнительный режим — одна колонка с крупными стикерами (01); название этапа открывает выбор всех пяти этапов, стрелки и горизонтальный свайп переключают соседние. «Мой день» (03) — самостоятельный экран фокуса, сроков и напоминаний. Редактор задачи — отдельный полноэкранный лист.

Навигация снизу: Доска, Сегодня, создание задачи, Ещё. Фильтры открываются отдельной панелью с числом активных фильтров. Перемещение через явное меню; перетаскивание только дополнительное. После подтверждения API — короткая анимация приклеивания и возможность отменить действие. Для зависимостей сохраняется проверка перед завершением. Порядок можно менять через меню «Выше / Ниже».

Области нажатия минимум 44–48 CSS px; поля ввода не мельче 16 px. Длинные заголовки переносятся. Фиксированные панели учитывают safe area и экранную клавиатуру, контент имеет отступ под панели. У редактора отдельная прокручиваемая область; кнопки сохранения не перекрывают бумагу. Ошибки отображаются возле поля и в видимой области. Отражение и фактура слабее, чем на десктопе; анимация отключаема и уважает reduced motion. Ночной режим сохраняет освещённость текста. Проверить масштабирование текста, клавиатуру, длинные имена, 0/1/100 задач и работу одной рукой.
