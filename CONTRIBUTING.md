# Участие в разработке

Спасибо за интерес к «Моей доске»! Ошибки и предложения можно обсуждать в Issues любого из двух репозиториев: [GitHub](https://github.com/Vadim-Bogdanchik/marker-board/issues) и [GitVerse](https://gitverse.ru/bogdanchik_vadim/marker-board).

Для сообщения об ошибке укажите ОС, версию Node.js, браузер, шаги воспроизведения, ожидаемый и фактический результат. Используйте демонстрационные задачи и удаляйте личные сведения со скриншотов. Базу `.local/board.sqlite`, экспорты реальных задач и секреты прикладывать не нужно.

Перед изменениями прочитайте [руководство разработчика](docs/guide.md#разработка). Для отдельной тестовой доски используйте `npm run qa`: она хранит данные в `.local/qa/` и не затрагивает основную базу.

Перед отправкой изменений выполните:

```sh
npm test
npm run test:integration
npm run build
```

В запросе на слияние опишите проблему, новое поведение и проверку. Для UI приложите скриншоты широкого и узкого экрана; сохраняйте управление с клавиатуры, читаемость кириллицы и настройку уменьшенного движения. Для новых SQL-миграций добавляйте отдельный файл — уже применённые миграции не редактируются.
